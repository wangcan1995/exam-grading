# 部署指南

> 目标：买完服务器后，照着本文档操作，把阅卷系统上线。
> 适用配置：Ubuntu 22.04 / 4核4G / 40GB SSD / 3M带宽 + COS 100G

---

## 整体架构

```
用户浏览器
    │
    ▼ (HTTPS)
┌─────────────────────────────────┐
│  Nginx 容器 (80/443)            │  ← 托管前端 + 反代API + HTTPS
│   ├─ /        → 前端静态文件     │
│   └─ /api/    → 后端 FastAPI    │
└────────────┬────────────────────┘
             ▼
┌─────────────────────────────────┐
│  Backend 容器 (FastAPI+OpenCV)  │  ← 判分核心
│   ├─ 数据库 → 持久化卷          │
│   └─ 图片   → COS 对象存储      │  ← (可选)减负系统盘
└─────────────────────────────────┘
```

**优势**：全 Docker 化，换服务器一条命令搬走；系统盘和数据/图片分离，永不满盘。

---

## 第 0 步：准备域名（可选但推荐）

如果有域名，先解析到服务器 IP（A 记录）。没域名也能用 IP 访问，只是没法上 HTTPS 免费证书。
下面文档里 `your-domain.com` 替换成你的域名或服务器 IP。

---

## 第 1 步：连接服务器

```bash
# 本地终端 (Git Bash / PowerShell)，用云厂商给的密码登录
ssh root@你的服务器IP
```

登录后先确认是 Ubuntu：
```bash
cat /etc/os-release | grep PRETTY
# 应输出: PRETTY_NAME="Ubuntu 22.04.x LTS"
```

---

## 第 2 步：初始化服务器（装 Docker + 防火墙）

执行项目自带的初始化脚本（见下文「上传代码」后），或手动执行：

```bash
# 更新系统
apt update -y && apt upgrade -y

# 安装 Docker (官方脚本，一条命令搞定)
curl -fsSL https://get.docker.com | bash
systemctl enable docker && systemctl start docker
docker --version              # 确认装好

# 配防火墙 (开放 Web + SSH 端口)
ufw allow 22/tcp
ufw allow 80/tcp
ufw allow 443/tcp
ufw --force enable
```

> 💡 国内服务器若 Docker 装得慢，可改用阿里云镜像源，见文末「常见问题」。

---

## 第 3 步：上传项目代码

### 方式 A：用 Git（推荐，方便后续更新）

先把代码推到 GitHub/Gitee，服务器上 clone：
```bash
apt install -y git
cd /opt
git clone https://github.com/你的用户名/exam-grading.git
cd exam-grading
```

### 方式 B：直接 scp 上传（无 Git 仓库时）

本地终端执行（把整个项目文件夹传上去）：
```bash
# Windows Git Bash
scp -r "/d/code标准/JGBS/exam-grading" root@你的服务器IP:/opt/
```

---

## 第 4 步：配置生产环境

```bash
cd /opt/exam-grading

# 复制生产配置模板
cp .env.prod.example .env.prod

# 编辑配置
nano .env.prod
```

**重点检查这几项**：

```bash
APP_ENV=prod
APP_DEBUG=false

# 数据库 (保持默认，存到持久化卷)
DATABASE_URL=sqlite:////app/data/exam_grading.db

# ===== 如果要用 COS 存图片(强烈推荐) =====
STORAGE_TYPE=cos
COS_SECRET_ID=你的腾讯云SecretId
COS_SECRET_KEY=你的腾讯云SecretKey
COS_REGION=ap-guangzhou              # 改成你 COS 桶所在区域
COS_BUCKET=exam-grading-1250000000   # 你的 COS 桶名
```

> COS 密钥获取：腾讯云控制台 → 访问管理 → API 密钥管理。
> 没配 COS 也能跑（`STORAGE_TYPE=local`），图片存服务器系统盘，但要留意磁盘空间。

---

## 第 5 步：构建前端

前端要构建成静态文件，由 Nginx 托管（不在生产跑 node 开发服务器）：

```bash
cd /opt/exam-grading/frontend

# 装依赖 + 构建 (服务器需要 node，临时装一个)
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs
npm install --registry=https://registry.npmmirror.com
npm run build

# 构建产物在 frontend/dist/，会由 nginx 容器托管
cd ..
```

---

## 第 6 步：启动服务 🚀

```bash
cd /opt/exam-grading

# 构建并启动 (首次会构建后端镜像，约 3-5 分钟)
docker compose -f docker-compose.prod.yml up -d --build
```

**查看启动状态**：
```bash
docker compose -f docker-compose.prod.yml ps       # 容器状态
docker compose -f docker-compose.prod.yml logs -f  # 实时日志 (Ctrl+C 退出)
```

看到 `Application startup complete` 即启动成功。

---

## 第 7 步：验证访问

```bash
# 服务器本地测试
curl http://localhost/health
# 应返回: {"status":"ok"}
```

浏览器打开 `http://你的服务器IP`，能看到阅卷系统首页即成功！🎉

## 第 8 步：配置 HTTPS（有域名时强烈推荐）

免费的 Let's Encrypt 证书，自动续期：

```bash
# 装 certbot
apt install -y certbot

# 申请证书 (确保域名已解析到本服务器，且 80 端口可访问)
certbot certonly --standalone -d your-domain.com

# 证书生成在:
#   /etc/letsencrypt/live/your-domain.com/fullchain.pem
#   /etc/letsencrypt/live/your-domain.com/privkey.pem

# 复制证书到项目目录
mkdir -p deploy/certs
cp /etc/letsencrypt/live/your-domain.com/*.pem deploy/certs/
```

**启用 HTTPS**：编辑 `deploy/nginx.conf`，按文件内注释取消 HTTPS 部分注释，改 `your-domain.com`，然后重启 nginx：
```bash
docker compose -f docker-compose.prod.yml restart nginx
```

设置证书自动续期：
```bash
crontab -e
# 加一行 (每月1号检查续期):
0 0 1 * * certbot renew --quiet && cp /etc/letsencrypt/live/your-domain.com/*.pem /opt/exam-grading/deploy/certs/ && docker compose -f /opt/exam-grading/docker-compose.prod.yml restart nginx
```

## 日常运维

### 查看日志
```bash
cd /opt/exam-grading
docker compose -f docker-compose.prod.yml logs -f backend   # 后端日志
docker compose -f docker-compose.prod.yml logs -f nginx     # Nginx 日志
```

### 更新代码
```bash
cd /opt/exam-grading
git pull                                    # 拉新代码
docker compose -f docker-compose.prod.yml up -d --build    # 重建启动
```

### 数据备份（定时执行）
```bash
# 手动备份
bash deploy/backup.sh

# 自动备份: 每天凌晨3点
crontab -e
# 加一行:
0 3 * * * cd /opt/exam-grading && bash deploy/backup.sh
```
备份文件在 `backups/` 目录，含数据库 + 配置（图片建议存 COS，无需备份）。

### 停止/重启
```bash
docker compose -f docker-compose.prod.yml stop      # 停止
docker compose -f docker-compose.prod.yml restart   # 重启
docker compose -f docker-compose.prod.yml down      # 停止并删除容器(数据不丢)
```

## 数据存放位置

| 数据 | 位置 | 备份方式 |
|---|---|---|
| 数据库 | Docker volume `backend_db` | `backup.sh` 定时打包 |
| 配置 | `.env.prod` | `backup.sh` 一并打包 |
| 图片(本地模式) | Docker volume `backend_data` | 建议转 COS |
| 图片(COS模式) | 腾讯云 COS | COS 自带高可用，无需备份 |

## 常见问题

### Q: Docker 装得慢/拉镜像慢？
国内服务器配置镜像加速：
```bash
mkdir -p /etc/docker
cat > /etc/docker/daemon.json <<'EOF'
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://dockerproxy.com"
  ]
}
EOF
systemctl restart docker
```

### Q: 上传图片报 413 错误？
nginx 默认限制 1MB，已在 `nginx.conf` 配置 `client_max_body_size 20m`。若还报错检查该配置。

### Q: 判分接口超时？
已在 nginx 配置 `proxy_read_timeout 120s`。批量判分仍超时的话，考虑改异步（第2期 Celery）。

### Q: 磁盘空间不足？
```bash
df -h                              # 查看磁盘占用
docker system prune -a             # 清理无用镜像(谨慎)
du -sh /opt/exam-grading/*         # 找大文件
```
长期方案：图片转 COS，系统盘只留系统和数据库。

### Q: 改了配置后不生效？
```bash
docker compose -f docker-compose.prod.yml down
docker compose -f docker-compose.prod.yml up -d --build
```

### Q: 忘记服务器密码/进不去？
各云厂商控制台都有「重置实例密码」功能，重置后用新密码 ssh 登录。
