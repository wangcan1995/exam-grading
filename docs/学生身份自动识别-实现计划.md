## 一、需求背景

当前扫描答题卡时，学生学号和姓名需要老师**手动输入**，效率低且易错。本需求实现**扫描即自动获取学生身份**：

| 字段 | 识别方式 | 准确率 | 角色 |
|---|---|---|---|
| 学号 | OMR 填涂区（复用现有技术） | >99% | **主键**，关联学生身份 |
| 姓名 | OCR 识别卷面手写 | 70-85% | **核验**，与名册比对，不作主键 |
| 班级/年级 | 学号反查名册 | 100% | 来自名册 |

**核心思路**：学号是唯一键，姓名/班级本就该来自数据库（学生名册）而非卷面。卷面手写姓名仅作辅助核验。

## 二、整体工作流

```
扫描答题卡
  → ① 预处理 + 锚点定位 + 透视矫正（已有）
  → ② 【新增】OMR 识别学号填涂区 → 得到学号字符串
  → ③ 【新增】用学号查学生名册 → 自动填充姓名/班级
  → ④ 【新增·可选】OCR 识别卷面姓名框 → 与名册姓名比对核验
  → ⑤ 题块切分 + OMR 判分（已有）
  → ⑥ 汇总：带上学号、姓名、核验状态、判分结果
```

## 三、关键设计

### 1. 学号填涂区结构

学号 N 位（默认 6 位，可配置），每位 0-9 十个气泡，**竖排**布局（每列一个数字位，10 行 0-9）：

```
位:   ①   ②   ③   ④   ⑤   ⑥
 0    ○   ○   ●   ○   ○   ○      ← 学号 002100
 1    ○   ○   ○   ●   ○   ○
 2    ○   ●   ○   ○   ○   ○      (每列正好涂一个 = 该位数字)
 3    ○   ○   ○   ○   ○   ○
 ...
 9    ○   ○   ○   ○   ○   ○
```

**复用现有 `detect_marked_options`**：把每列当一道"题"，10 个选项（数字 0-9），检测每列涂了哪个数字。

**识别置信度规则**：
- 每列正好涂 1 个 → confidence 高，可靠
- 某列多涂 / 未涂 → confidence 低，标记"学号识别存疑"，进人工核对队列

### 2. 模板 JSON 扩展（向后兼容）

在现有模板结构里新增 `student_id_region` 字段，旧模板无此字段时自动跳过学号识别：

```json
{
  "anchors": {
    "top_left": [60, 60],
    "top_right": [1180, 60],
    "bottom_right": [1180, 1694],
    "bottom_left": [60, 1694]
  },
  "student_id_region": {
    "digit_count": 6,
    "digit_positions": [
      [
        {"option": "0", "cx": 200, "cy": 180, "radius": 20},
        {"option": "1", "cx": 200, "cy": 220, "radius": 20},
        ... 每位 10 个气泡（数字 0-9）
      ],
      ... 共 digit_count 组
    ]
  },
  "questions": [...]
}
```

## 六、学号识别模块设计（`app/ai/image/student_id.py`）

```python
from dataclasses import dataclass
from app.ai.image.omr import detect_marked_options, BubbleRegion

@dataclass
class StudentIdResult:
    student_id: str           # "002100"
    confidence: float         # [0, 1]
    digit_details: list       # 每位的检测明细 [{digit:0/多涂/未涂, options:[...]}]
    needs_review: bool        # 是否需人工核对

def recognize_student_id(binary, digit_positions):
    """识别学号填涂区。

    :param digit_positions: 模板里的 [[10个BubbleRegion], ...] 每位一组
    :return: StudentIdResult
    """
    digits = []
    all_confident = True
    for col_bubbles in digit_positions:
        # 每列当一道题：10个选项(0-9)
        regions = [BubbleRegion(o["option"], o["cx"], o["cy"], o["radius"])
                   for o in col_bubbles]
        results = detect_marked_options(binary, regions)
        marked = [r.option for r in results if r.marked]
        if len(marked) == 1:
            digits.append(marked[0])        # 该位数字
        else:
            digits.append("?")              # 多涂/未涂
            all_confident = False
    student_id = "".join(digits)
    confidence = 1.0 if all_confident else 0.4
    return StudentIdResult(
        student_id=student_id,
        confidence=confidence,
        needs_review=not all_confident or "?" in student_id,
    )
```
